# CakesCats sites

Source of the six CakesCats websites. Every site is plain static HTML generated by a small Python script — no CMS, no database, nothing to hack on the server.

| Site | What |
|---|---|
| [cakescats.com](https://cakescats.com/) | Consulting: crisis communications, PR, AI |
| [main.cakescats.com](https://main.cakescats.com/) | CakesCats products and security insights |
| [os.cakescats.com](https://os.cakescats.com/) | VirtualCatsOS — private workspace for Mac |
| [phone.cakescats.com](https://phone.cakescats.com/) | CakesCats Phone — Pixel with GrapheneOS |
| [vpn.cakescats.com](https://vpn.cakescats.com/) | VPN Router |
| [llm.cakescats.com](https://llm.cakescats.com/) | LLM EdgeBox — private AI |

Free setup guides for the products live in a separate repo: [cakescats/guides](https://github.com/cakescats/guides).

## Structure

```
lib.py      design system: CSS, JS, header/footer, cards, pricing tiers, ecosystem block
sites.py    page content for every site in English and Russian, prices
build.py    renders everything into out/<domain>/ (+ .htaccess, robots.txt, sitemap.xml)
deploy.sh   uploads out/ to the hosting over SSH
img/        images (WebP)
legal/      privacy and cookie policy text (Polish)
```

Every page exists in English (`/`) and Russian (`/ru/`). First-time visitors with a Russian-language browser are sent to `/ru/` automatically.

## Editing

- **Texts and prices** — `sites.py`. Each string is written as `t("English", "Русский")`. Product “from” prices for the cards are in `PRICES`; full price tiers are in each product's `tiers_items`.
- **Design** — the `CSS` block in `lib.py`. After changing CSS, bump `site.css?v=…` in `page()` so browsers reload it.
- **List of sites / cross-links** — `SITES` and `ECO` in `lib.py`.

## Build and deploy

```bash
python3 build.py                     # → out/<domain>/
DEPLOY=user@host DEPLOY_PORT=22 SSH_KEY=~/.ssh/key ./deploy.sh              # all sites
DEPLOY=user@host DEPLOY_PORT=22 SSH_KEY=~/.ssh/key ./deploy.sh vpn.cakescats.com   # one site
```

`deploy.sh` rebuilds, replaces the contents of each document root (keeping `.well-known` for certificate renewal) and checks that the site answers. HTTPS certificates are issued and renewed on the server by acme.sh.
